## How I build

I run AI coding agents (Claude Code, Codex) the way I'd run a product team:
- written agent rules
- phased plans with measurable success criteria
- explicit points where a person has to approve before the agent continues
- a definition of done that CI enforces: lint, type-check, build, tests

The same system builds both Pamti and the Promobet platform, on a TypeScript monorepo running on Cloudflare Workers with Hono, oRPC, Drizzle / Postgres and React 19. AI writes most of the code; I own the architecture, the plan and what "done" means.
